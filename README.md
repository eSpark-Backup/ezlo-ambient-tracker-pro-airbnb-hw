# ezlo-ambienttrackerpro-airbnb-hardware
 This product will be a variant / extension of the Ambient Tracker Pro but this will be targeted at AirBnB for home owners that want to rent their spaces using AirBnB but also want to keep an eye on their rentals.
 
 ## Hardware Development v1.0
 * The product will have all the basic sensors from the Ambient Tracker Pro namely:
     * PMS5003 sensor
     * BME680 sensor
     * LTR-303ALS-01 sensor
     * SK6812-EC20 LED
     * BGT60 radar sensor / Hilink sensor (topic of discussion)

* The product will not have DW3000 chip.
* The product will not have the Ethernet capabilities.
* The product will feature 4 x microphones with direction feature support.
* The product will have sensors for smoke detection, marijuana detection and vaping detection (independantly)
* The product will have tamper detection.
* The product will have the capability to produce an incident report (cloud part)
* The product will not have Ethernet capability.
* The product will feature mold detection and alarm detection capabilities.
* The product may be given battery rechargeable via USB-C as well (topic of discussion)
